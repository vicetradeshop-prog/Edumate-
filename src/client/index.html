EduMate se prépare…

Le démarrage prend plus de temps que prévu. Causes fréquentes et solutions :
  • Le site sort de veille (après une période d'inactivité). Le réveil prend 30 à 60 secondes → patiente un peu puis recharge la page.
  • Un ancien fichier est en cache → recharge en vidant le cache : Ctrl + Maj + R (Windows) ou Cmd + Maj + R (Mac), ou ouvre une fenêtre de navigation privée.
  • Un proxy/pare-feu bloque le JavaScript (réseau scolaire) → teste en 4G/5G ou sur un autre réseau.
